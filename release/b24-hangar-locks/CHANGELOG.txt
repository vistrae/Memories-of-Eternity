B24 - Hangar protection, showroom catalog and offline playtest improvements

Hangar protection now restores locked suits, parts and components after the offline inventories load. Confirmed lock and unlock changes are saved immediately, including when the game is closed before leaving the Hangar. The original native preference format and player keys are retained, with a guard preventing partially loaded lists from overwriting saved protection. Existing local saves keep their separate protection settings; resources, owned items and unrelated options are unchanged.

Dormitory showroom listings now consolidate equivalent decorations into one product. All 283 archived catalog IDs remain valid; the catalog contains 161 distinct product groups, with 154 initially visible catalog entries and seven earned set rewards. Different original prices, set roles, scores, effects and other gameplay differences remain distinct. Existing ownership and saved room placements retain their original IDs. If a room already owns an equivalent decoration, reusing it does not charge another purchase or grant a duplicate raw ID. Original prices, per-Pixie collections, decoration scores and set prerequisites remain in place.

This release also publishes the previously local B22 improvements. Each of the seven beginner Draw banners (shop IDs 4-10) allows one purchase per selected save per local calendar week, resetting Monday at 00:00. Original Gem prices are unchanged. Three other supported paid suit-draw banners rotate every 30 minutes; their selections persist per save across shop reopening and game restarts. Friendship single and ten draws (IDs 13 and 14) remain permanently available outside those three slots at their original CP prices. Off-rotation and already-purchased weekly offers are checked before payment or reward rolls.

AP now has a cap of 60 and regenerates 1 AP every 15 minutes. BP retains a cap of 20 and regenerates 1 BP every 15 minutes. Manual content retains zero AP/BP cost, and eligible Auto Clear retains its BP cost. The seven Gem packages grant 10, 50, 160, 330, 560, 850 and 1,200 Gems for 5, 10, 20, 30, 40, 50 and 60 AP respectively. HOT cash-shop products retain their existing 20 AP price and progression/purchase requirements.

Daily Missions now has four tabs: Normal Dailies, Quick Missions, One-Time Missions and Events. Normal Dailies is selected when the scene opens. Each of the seven tagged Crossover missions can be cleared once per local clock hour, with a countdown and a separate persistent receipt for each mission in the selected save. Previous one-time Crossover completion history remains available without permanently blocking the hourly missions. Daily list initialization and loading transitions have been corrected, and the unwanted legacy Korean countdown labels have been removed from Draw cards.

A protected Admin testing panel is available through the existing options interface. It requires authentication and a verified backup of the selected save before test tools become available. The original pre-Admin baseline is retained until a successful restore; additional backups preserve that baseline. Restore returns the selected save to that baseline and closes the game to prevent stale cached data being written back; other save slots and updater resources remain separate. Successful restore retires the active baseline pointer so a future session can protect newly earned regular progress. No passcode or private save data is included in the public updater sources.

Existing B21 content remains included: offline furniture purchases and saved layouts, earned set rewards, daily dormitory Heart claims, the 70 HOT cards with progression and purchase limits, the six Pension missions granting the requested 50,000 Credits per clear, and per-save Codex acquisition and episode requirements. Three local save profiles, Captain names, typed RESET, the 26-Pixie offline helper roster and its 30-minute refresh behavior remain available. Updated interfaces follow the game's existing styling.

The Windows updater now requires an explicitly supplied serial for a running MOE-Split-Test emulator. It never starts, stops or restarts an emulator, changes its network settings or restarts ADB. The MOE AVD and emulator-5556 are protected and rejected. Update checks and downloads can run without a device; updates and rollback require root access already enabled and use serial-specific caches and backups. Use the example and actual serial instructions in the included README.

Keep the existing game installed. Use Update on the title screen, or install MOE-Android-Update-Installer.apk for an older supported installation, then approve Android's update prompt. The helper remains version 1.4 (code 5). Canonical and standard SAI signing identities are supported; only a matching signed APK is selected. Compatible installed resource splits and existing local saves are retained. Do not uninstall the game or clear its data. Update checking remains optional and offline play is retained. This release updates an existing asset installation; it does not include a fresh full asset set. The Windows updater package supports the existing Windows emulator playtest and is not a standalone Unity Windows conversion.

The final signed game, diagnostic reports and independent package checks are bound to the frozen B24 artifact. Testing on the isolated Android 11 emulator does not establish compatibility with every physical phone.
